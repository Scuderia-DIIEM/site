# Icone delle skills

Inserisci qui le 6 immagini PNG trasparenti usando questi nomi esatti:

- `corso-sicurezza.png` - Corso sicurezza
- `manutenzione.jpg` - Manutenzione
- `stampante-3d.png` - Stampante 3D
- `stampante-resina.png` - Stampante a resina
- `saldare.png` - Saldare
- `core.png` - Core

Per assegnare le skills a una persona, aggiungi la proprietà `skills` nel relativo oggetto di `team-members.json`:

```json
"skills": ["manutenzione", "saldare", "core"]
```

L'ordine dell'array è l'ordine delle icone. Nelle anteprime vengono mostrate al massimo le prime quattro.
