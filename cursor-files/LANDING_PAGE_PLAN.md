## 🎨 Design & UX Planning

### 1. Visual Identity

- [x] **Color Palette** (Scuderia DIIEM Brand Colors) - ✅ DEFINED
  - **Primary color**: 
    - `#012245` - **Prussian Blue** (Main brand color)
    - Inky, profound blue filled with gravitas and mystery
    - Use for: Headers, navigation, primary backgrounds, main brand elements
  - **Secondary Primary**: 
    - `#112844` - **Prussian Blue (variant)**
    - Slightly lighter variant of primary
    - Use for: Hover states, gradients, depth variations
  - **Accent color**: 
    - `#f4792b` - **Pumpkin Spice** (Main accent)
    - Bold and spicy, exudes energy and excitement
    - Use for: CTAs, highlights, buttons, important elements, hover effects
  - **Supporting colors**:
    - `#202d42` - **Deep Space Blue**
      - Infinite dark blue echoing the cosmos
      - Use for: Dark backgrounds, deep sections, contrast elements
    - `#463b3e` - **Deep Mocha**
      - Deep and dark with mocha richness, radiates warmth
      - Use for: Secondary backgrounds, text accents, warm tones
    - `#b86432` - **Burnt Caramel**
      - Deep, rich, and earthy
      - Use for: Secondary accents, gradients, warm highlights
  - **Text colors**: 
    - Primary text: White (`#ffffff`) on dark backgrounds, `#012245` on light backgrounds
    - Secondary text: Light gray (`#e5e7eb` or `#9ca3af`) on dark, `#4b5563` on light
  - **CTA button colors**: 
    - Primary: `#f4792b` (Pumpkin Spice) with white text
    - Hover: Lighter shade or `#b86432` (Burnt Caramel)
    - Secondary: `#012245` (Prussian Blue) with white text

- [ ] **Typography**
  - **Heading font**: 
    - Bold, modern sans-serif (e.g., Inter, Poppins, Montserrat, Racing-inspired custom font)
    - Condensed options for impact (display typography)
  - **Body font**: 
    - Clean, readable sans-serif (Inter, system fonts)
    - Excellent readability at all sizes
  - **Font sizes hierarchy**: 
    - Hero: 4xl-6xl (72px-96px)
    - Section titles: 3xl-4xl (48px-64px)
    - Subheadings: xl-2xl (20px-32px)
    - Body: base-lg (16px-18px)
  - **Line heights**: Generous for readability (1.5-1.8)
  - **Letter spacing**: Slightly tight for headings (racing aesthetic), normal for body

- [ ] **Imagery Style**
  - **Photography**: 
    - High-speed action shots
    - Dramatic lighting (track lighting, golden hour)
    - Close-ups of details (tires, engines, team focus)
    - Wide-angle track/venue shots
  - **Illustration style**: 
    - Technical drawings (optional)
    - Geometric patterns (speed lines, checkered patterns)
    - Minimalist iconography
  - **Icon style**: 
    - Modern, outlined or filled
    - Consistent stroke width
    - Racing-themed (wheels, flags, speedometers)
  - **Image aspect ratios**: 
    - Hero: 21:9 or 16:9 (cinematic)
    - Cards: 4:3 or 16:9
    - Team photos: 1:1 or 3:2
  - **Visual effects**: 
    - Motion blur overlays
    - Speed line graphics
    - Gradient overlays on images

### 4. Interactive Elements & Animations

- [ ] **Button Styles**: 
  - Primary: Bold, high-contrast, with hover effects (scale, glow, shadow)
  - Secondary: Outlined or ghost style
  - Text links: Underlined on hover, color transitions

- [ ] **Hover States**: 
  - Smooth scale transforms (1.05x - 1.1x)
  - Shadow/elevation changes
  - Color transitions (300ms ease-in-out)
  - Background color shifts

- [ ] **Form Inputs**: 
  - Modern, clean styling
  - Focus states with outline/glow
  - Placeholder styling
  - Error states (red accents)

- [ ] **Loading States**: 
  - Skeleton loaders for content
  - Smooth fade-in animations
  - Spinner or progress indicators

- [ ] **Animations & Transitions** (Emphasis on Smooth & Modern):
  - **Scroll Animations**: 
    - Fade-in on scroll (framer-motion or Intersection Observer)
    - Slide-in from sides (left/right)
    - Scale-up on reveal
    - Stagger animations for cards/grids
  - **Page Transitions**: 
    - Smooth fade transitions
    - Subtle page load animations
  - **Micro-interactions**: 
    - Button hover effects (transform, shadow)
    - Card hover effects (lift, glow)
    - Image zoom on hover
    - Icon animations (rotate, scale)
  - **Motion Design**: 
    - Parallax scrolling for hero sections
    - Speed line animations
    - Particle effects (optional, subtle)
    - Smooth scroll behavior
  - **Performance**: 
    - Use CSS transforms (translate, scale) instead of position changes
    - Use `will-change` property sparingly
    - Prefer `requestAnimationFrame` for complex animations
    - Lazy-load animations below the fold

- [ ] **Scroll Behavior**: 
  - Smooth scrolling (`scroll-behavior: smooth`)
  - Scroll-triggered animations
  - Sticky navigation on scroll
  - Progress indicator (optional)

   ```bash
   npm install -D tailwindcss postcss autoprefixer
   ```

2. **Initialize Configuration**:
   ```bash
   npx tailwindcss init -p
   ```

3. **Configure `tailwind.config.js`**:
   ```javascript
   module.exports = {
     content: [
       './pages/**/*.{js,ts,jsx,tsx,mdx}',
       './components/**/*.{js,ts,jsx,tsx,mdx}',
     ],
     theme: {
       extend: {
         colors: {
           // Scuderia DIIEM brand colors - Main palette
           primary: '#012245',        // Prussian Blue - Main brand color
           'primary-variant': '#112844', // Prussian Blue variant
           secondary: '#f4792b',      // Pumpkin Spice - Accent/CTA color
           'deep-space': '#202d42',   // Deep Space Blue - Backgrounds
           mocha: '#463b3e',          // Deep Mocha - Text/secondary
           caramel: '#b86432',        // Burnt Caramel - Warm accent
           // Semantic color aliases
           accent: '#f4792b',         // Alias for secondary (Pumpkin Spice)
           'bg-dark': '#202d42',      // Dark background
           'text-primary': '#202d42',  // Primary text on light
           'text-secondary': '#463b3e', // Secondary text
         },
         fontFamily: {
           sans: ['Inter', 'system-ui', 'sans-serif'],
           display: ['Poppins', 'sans-serif'], // For headings
         },
         animation: {
           'fade-in': 'fadeIn 0.6s ease-in-out',

             '0%': { transform: 'translateX(-30px)', opacity: '0' },
             '100%': { transform: 'translateX(0)', opacity: '1' },
   ```

### Animation Strategy with Tailwind + Framer Motion

**Use Tailwind CSS for:**
- Simple hover effects (scale, shadow, color transitions)
- Basic transitions (fade, slide with Tailwind classes)
- Utility-based animations (spin, pulse, bounce)
- Responsive utilities

**Use Framer Motion for:**
- Scroll-triggered animations
- Complex animation sequences
- Gesture-based interactions
- Layout animations
- Stagger animations for lists/grids

**Example Pattern:**
```tsx
// Component combining Tailwind + Framer Motion
import { motion } from 'framer-motion'

<motion.div
  initial={{ opacity: 0, y: 20 }}
  whileInView={{ opacity: 1, y: 0 }}
  viewport={{ once: true, margin: '-100px' }}
  transition={{ duration: 0.6 }}
  className="p-6 bg-white rounded-lg shadow-md hover:shadow-xl transition-shadow"
>
  {/* Content */}
</motion.div>
```

## 🎨 Modern Design Patterns & Best Practices

### Visual Design Trends for Racing Websites
- [ ] **Bold Typography**: Large, impactful headlines with contrast
- [ ] **High-Contrast Elements**: Dark backgrounds with bright accents
- [ ] **Dynamic Imagery**: Action shots with motion blur effects
- [ ] **Geometric Patterns**: Speed lines, grid overlays, angular shapes
- [ ] **Gradient Accents**: Subtle gradients for depth and modern feel
- [ ] **Glassmorphism**: Frosted glass effects (optional, use sparingly)
- [ ] **Minimal Navigation**: Clean, unobtrusive navigation
- [ ] **Generous White Space**: Let content breathe
- [ ] **Micro-interactions**: Every interactive element should respond

### Animation Best Practices
- [ ] **Performance First**: Always prioritize 60fps animations
- [ ] **Respect Preferences**: Honor `prefers-reduced-motion` media query
- [ ] **Purposeful Animations**: Each animation should serve a purpose
- [ ] **Stagger Delays**: Use staggered animations for lists/grids (100-200ms intervals)
- [ ] **Easing Functions**: Use natural easing (ease-out for entrances, ease-in for exits)
- [ ] **Duration Guidelines**:
  - Micro-interactions: 150-300ms
  - Standard transitions: 300-500ms
  - Complex animations: 500-800ms
  - Page transitions: 400-600ms

### Tailwind CSS Patterns for Modern UI
```tsx
// Modern Card with Hover Effect
<div className="group relative overflow-hidden rounded-xl bg-white shadow-lg transition-all duration-300 hover:scale-105 hover:shadow-2xl">
  {/* Content */}
</div>

// Animated Gradient Background
<div className="bg-gradient-to-br from-primary via-secondary to-accent animate-gradient">
  {/* Content */}
</div>

// Glassmorphism Effect (if desired)
<div className="backdrop-blur-md bg-white/10 border border-white/20 rounded-xl">
  {/* Content */}
</div>
```
